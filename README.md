# Laboratorio de pruebas automatizadas

Aplicación de ejemplo en Flask para practicar pruebas y análisis de seguridad
en un entorno local.

## Requisitos

- Python 3.10 o superior
- Git

## Ejecutar en Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py app.py
